Icon & UI component research — Buy n Try

Eight visual systems (not single icons), each applied to the same chrome: nav actions, trust strip, category circles, and cart/wishlist buttons. Goal: feel hand-finished and ownable — not “default Lucide storefront.” Aligns with T-32: one family, no emoji UI, forest on cream, BNT seal as anchor.

Where you are today

  • ~80+ components import Lucide (search, cart, truck, banknote, chevrons, dialogs).
  • Category circles already use custom filled SVGs in gadget-category-glyphs.tsx (earbuds, watch, speaker…) — stronger than generic stock.
  • T-32 target: 1.75px stroke UI icons + refined category silhouettes; ban Sparkles/Gift as chrome; stars as drawn SVG only.
  • Gap: Lucide reads “SaaS template”; category glyphs read “boutique hardware” — two languages fighting each other.

What “new to the world” means here

  • Ownable metaphor: icons tied to BNT seal geometry (ring, arc, cream well) — shoppers subconsciously link UI to your mark.
  • Category = product stage: same cream cutout + forest mass as PDP cards (extend existing glyphs, don’t swap to outline sets).
  • Trust for PK: COD / delivery / returns drawn as calm commerce glyphs, not “fintech” or “gift box” clichés.
  • Production path: hand-tuned SVG React components (like today’s glyphs) or a small 24-icon kit exported once — not a live CDN of random AI icons.
